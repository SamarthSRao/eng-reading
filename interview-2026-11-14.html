Coding exercises — Go (5, basic to advanced)

  • Ex 1 · Basic · Word-frequency counter
    Task: Read stdin, count words with a map[string]int, print the top 10.
    Verify: Output matches tr -cs A-Za-z &#x27;\n&#x27; | sort | uniq -c | sort -rn | head on a 10 MB file; record your time vs the shell pipeline. Source: Go by Example: Maps
  • Ex 2 · Basic · Race on a shared counter
    Task: Start 1,000 goroutines that each increment one counter, first unsynchronised, then with sync.Mutex, then with sync/atomic.
    Verify: Predict the unsynchronised result first; run with go run -race; time all three versions. Source: Data Race Detector
  • Ex 3 · Intermediate · Worker pool with clean shutdown
    Task: N workers hash every file in a directory tree via a jobs channel and a results channel, then shut down cleanly.
    Verify: Throughput for N = 1, 2, 4, 8 vs runtime.NumCPU(); runtime.NumGoroutine() is back to 1 at the end (no leaks). Source: Go Concurrency Patterns: Pipelines and cancellation
  • Ex 4 · Intermediate · Context-aware parallel fetcher
    Task: Fetch 50 URLs with at most 5 in flight, a per-request timeout, and cancel everything on the first error.
    Verify: Against an httptest server with slow handlers, all work stops within 100 ms of the first error; run with -race. Source: Go Concurrency Patterns: Context
  • Ex 5 · Advanced · Allocation hunt
    Task: Write a JSON-lines parser, benchmark it, then cut allocations using escape-analysis output and sync.Pool.
    Verify: Record ns/op and allocs/op before and after with -benchmem; confirm with go build -gcflags=-m and a pprof alloc profile. Source: Profiling Go Programs
