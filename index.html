Project ideas

  • MetaCirc Compilers — implements a metacircular eval/apply from SICP §4.1 "The Metacircular Evaluator".
  • MaglevTable Infrastructure — implements Maglev’s consistent hashing lookup table from Cloudflare, "High Availability Load Balancers with Maglev".
  • BloomGate Backend — implements a Bloom-filter doorkeeper in front of cache-aside from Arpit, "Bloom Filters".
  • InnoPages Databases — implements InnoDB-style B+ leaf/internal page sketches from Jeremy Cole, "B+Tree index structures in InnoDB".
  • SecretSh Terminals — implements a friendlier read–parse–execute loop inspired by Julia Evans, "Reasons I still love the fish shell" on top of Brennan’s shell shape.
  • LazyWebP Frontend — implements lazy-load + WebP srcset from browser-level lazy loading and Use WebP images.
  • CliffWalk Reinforcement learning — implements the cliff-walking Q-learning vs SARSA experiment from Sutton & Barto §6.5.
  • TwoQueueSim Napkin math — implements the one-queue vs two-queue comparison from Brooker, "One or Two? How Many Queues?".
  • ChainThen JavaScript — implements promise chaining + error recovery from Promises chaining and Error handling with promises.
  • CtxCause Go — implements cancellation-cause diagnostics from the patterns in HN: What canceled my Go context? and Contexts and structs.
  • HashBench Java — implements a Collections microbench from Baeldung HashMap and ArrayList vs LinkedList vs HashMap.
  • LoxCall Compilers — implements function declarations, calls, return and a native clock() from Crafting Interpreters, ch. 10 "Functions".
  • SubPlace Infrastructure — implements Uber's subclustered shard placement and greedy skew-aware donation from the Uber M3DB article.
  • SkiCache Backend — implements linear elastic caching (ski-rental TTLs, with LRU only when the cache is full) from the Google Research post.
  • BulkLeaf Databases — implements bottom-up B+tree bulk loading into slotted pages, the technique behind the Databricks Lakebase load article.
  • CtrlKeys Terminals — implements raw-mode line editing with the control codes from Julia Evans's post inside your shell.
  • StyleCost Frontend design & performance — implements GitHub's CSS-in-JS vs CSS Modules comparison from the GitHub post, and measures what it does to your hero image's LCP.
  • ExpSarsa Reinforcement learning — implements Expected Sarsa from Sutton & Barto (2nd ed.), §6.6, and compares it with Sarsa and Q-learning across step sizes on cliff walking.
  • ShedGate Napkin math — implements Stripe's request-rate limiter, concurrent-requests limiter and fleet-usage load shedder from the Stripe post.
  • CallStream JavaScript — implements Liskov & Shrira's promises and call-streams, including two-stream composition, from the paper below.
  • SemPipe Go — implements the counting semaphore from OSTEP, ch. 31 "Semaphores" in Go, then a context-aware weighted version that bounds a pipeline stage.
  • HopMap Java — implements hopscotch hashing from Herlihy, Shavit & Tzafrir (paper below) as a Java map, benchmarked against HashMap.
  • LoxBranch Compilers — implements if, while, for and short-circuit and/or from Crafting Interpreters, ch. 9 "Control Flow".
  • BandaidLB Infrastructure — implements load-feedback load balancing from the Dropbox Bandaid article.
  • CacheFrontMini Backend — implements an integrated read-through cache with change-data-capture invalidation, shaped by Uber's CacheFront.
  • SlotPage Databases — implements the slotted page from Database Internals, ch. 3 "File Formats".
  • JobCtl Terminals — implements the job control features from Julia Evans's job-control post inside your shell.
  • AvifCurve Frontend design & performance — implements a codec comparison at matched quality, the experiment behind the Netflix AVIF post discussed in that thread.
  • DynaQ Reinforcement learning — implements Dyna-Q from Sutton & Barto, §9.2 "Integrating Planning, Acting, and Learning" (1st ed.; ch. 8 in the 2nd ed.).
  • OpenClosed Napkin math — implements the open vs closed load-generator experiment from Schroeder, Wierman & Harchol-Balter's paper (below).
  • LoopSim JavaScript — implements a tiny event-loop simulator from You Don't Know JS, Async & Performance, ch. 1 "Asynchrony: Now & Later".
  • TimeoutBox Go — implements every net/http server and client timeout from the Cloudflare guide, with a misbehaving client that proves each one fires.
  • MSQueue Java — implements the Michael–Scott lock-free queue from the paper below, then benchmarks it against ConcurrentLinkedQueue and LinkedBlockingQueue.
