we can generate code insanely fast with ai. millions of devs using copilot, prs flying, features shipping faster than ever

but the products aren't actually getting better

the bottleneck has moved

writing code was never the hard part. it's everything after. reviews getting overwhelmed, tests missing things, debugging ai generated code often taking longer than writing it, and those brutal 3am production fires

we just made chaos happen much faster
