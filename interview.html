Go — Basic · unit 3/36

Loops and conditionals: for, if, switch, range

Questions you must be able to answer aloud:

  • Go has only one loop keyword: show a while-loop, infinite loop and classic loop using for.
  • How does range work over a slice, map, string and channel?
  • Does switch fall through? What does fallthrough do?
  • Write FizzBuzz in Go. What is the scope of a variable declared in an if init statement?
