Coding exercises — Go (5, basic to advanced)

  • Ex 1 · Basic · Word-frequency counter
    Task: Read stdin, count words with a map[string]int, print the top 10.
    Verify: Output matches tr -cs A-Za-z &#x27;\n&#x27; | sort | uniq -c | sort -rn | head on a 10 MB file; record your time vs the shell pipeline. Source: Go by Example: Maps
  • Ex 2 · Basic · Race on a shared counter
    Task: Start 1,000 goroutines that each increment one counter, first unsynchronised, then with sync.Mutex, then with sync/atomic.
    Verify: Predict the unsynchronised result first; run with go run -race; time all three versions. Source: Data Race Detector
  • Ex 3 · Intermediate · Worker pool with clean shutdown
    Task: N workers hash every file in a directory tree via a jobs channel and a results channel, then shut down cleanly.
    Verify: Throughput for N = 1, 2, 4, 8 vs runtime.NumCPU(); runtime.NumGoroutine() is back to 1 at the end (no leaks). Source: Go Concurrency Patterns: Pipelines and cancellation
  • Ex 4 · Intermediate · Context-aware parallel fetcher
    Task: Fetch 50 URLs with at most 5 in flight, a per-request timeout, and cancel everything on the first error.
    Verify: Against an httptest server with slow handlers, all work stops within 100 ms of the first error; run with -race. Source: Go Concurrency Patterns: Context
  • Ex 5 · Advanced · Allocation hunt
    Task: Write a JSON-lines parser, benchmark it, then cut allocations using escape-analysis output and sync.Pool.
    Verify: Record ns/op and allocs/op before and after with -benchmem; confirm with go build -gcflags=-m and a pprof alloc profile. Source: Profiling Go Programs

Coding exercises — JavaScript (5, basic to advanced)

  • Ex 1 · Basic · Closure toolkit
    Task: Implement makeCounter, once(fn) and memoize(fn) (Map-backed) using only closures.
    Verify: Tests with node:test; memoize on a recursive fib(35) is at least 100x faster than the plain version. Source: Closures - MDN
  • Ex 2 · Basic · Todo list with event delegation
    Task: Build a todo list where ONE listener on the &lt;ul&gt; handles add, toggle and delete for 1,000 items.
    Verify: DevTools shows 1 click listener on the list, not 1,000; time adding 1,000 items with and without a DocumentFragment. Source: Event bubbling - MDN
  • Ex 3 · Intermediate · Promise combinators from scratch
    Task: Implement all, allSettled, race and pLimit(n) without using the built-ins.
    Verify: Timer-based tests check result order, first-rejection behaviour, and that pLimit(3) never runs more than 3 tasks at once. Source: Promise.all() - MDN
  • Ex 4 · Intermediate · fetch with retry, backoff and abort
    Task: Write fetchRetry(url, {retries, timeoutMs}) with exponential backoff plus jitter and an AbortController timeout.
    Verify: A local server that fails 2 of every 3 requests; assert attempt count and that gaps grow roughly 100, 200, 400 ms. Source: AbortController - MDN
  • Ex 5 · Advanced · Parallel sum with worker_threads
    Task: Sum a 100M-element Float64Array using worker_threads and a SharedArrayBuffer.
    Verify: Speedup for 1, 2, 4, 8 workers vs a single thread; compare with copying chunks via postMessage and explain the gap. Source: Node.js worker_threads

Coding exercises — Java (5, basic to advanced)

  • Ex 1 · Basic · Account hierarchy and equals/hashCode
    Task: Model an abstract Account with Savings and Checking subclasses and an interface; override equals and hashCode.
    Verify: JUnit tests; show a HashSet holding duplicates when hashCode is NOT overridden, and one entry when it is. Source: Java Tutorial: Interfaces and Inheritance
  • Ex 2 · Basic · Collections benchmark
    Task: Compare ArrayList, LinkedList and ArrayDeque for 1M adds/removes at head, tail and middle.
    Verify: Write your predictions first; measure with JMH (not a bare loop); explain any surprise with cache behaviour. Source: OpenJDK JMH
  • Ex 3 · Intermediate · Bounded blocking queue
    Task: Build a thread-safe bounded queue with ReentrantLock and two Conditions; run 4 producers and 4 consumers.
    Verify: 1M items, checksum shows no loss or duplicates; throughput within 2x of ArrayBlockingQueue. Source: Condition (Java SE 21)
  • Ex 4 · Intermediate · Streams vs loops vs parallel
    Task: Group a 1M-row CSV by key and take the top 10 with Collectors.groupingBy, then a for-loop, then parallelStream.
    Verify: All three return identical results; time them and explain when the parallel version is slower. Source: java.util.stream package (Java SE 21)
  • Ex 5 · Advanced · GC lab
    Task: Run an allocation-heavy program under -Xmx256m with -Xlog:gc* on G1 and ZGC (or Parallel), then force an OOM and take a heap dump.
    Verify: Table of pause times and throughput per collector; find the leaking object type in the heap dump. Source: HotSpot Virtual Machine Garbage Collection Tuning Guide

Coding exercises — Networking (5, basic to advanced)

  • Ex 1 · Basic · TCP echo server
    Task: Write a TCP echo server and client that handle many concurrent clients.
    Verify: Works with nc; ss -tn shows the connections; measure mean round-trip for 1,000 messages. Source: Beej's Guide to Network Programming
  • Ex 2 · Basic · Hand-built DNS query
    Task: Build a DNS A-record query packet by hand (header + question), send it over UDP and parse the answer.
    Verify: Result equals dig +short; also follow a CNAME chain correctly. Source: Implement DNS in a weekend
  • Ex 3 · Intermediate · HTTP/1.1 server on raw TCP
    Task: Parse request line, headers and Content-Length bodies yourself; support keep-alive; return 400/404 correctly.
    Verify: curl -v works; throughput with wrk or ab; malformed requests never crash the server. Source: HTTP messages - MDN
  • Ex 4 · Intermediate · Loss lab with tc netem
    Task: Capture an HTTP download with tcpdump, count SYN/ACK/retransmits with a script, then add 5% loss with tc netem.
    Verify: Retransmit count and download time before vs after loss; explain the change from the capture. Source: tc-netem(8)
  • Ex 5 · Advanced · Reliable transfer over UDP
    Task: Implement stop-and-wait, then a sliding window (size 16) with sequence numbers, ACKs and retransmit timeouts.
    Verify: Send a 10 MB file under 10% loss and reordering; SHA-256 matches; throughput of stop-and-wait vs window 16. Source: RFC 9293: TCP

Coding exercises — AI Engineering (LLMs, RAG, agents, inference) (5, basic to advanced)

  • Ex 1 · Basic · Streaming LLM client with cost maths
    Task: Call an LLM (local Ollama or a hosted API) with streaming, count tokens, and compute cost per 1,000 requests.
    Verify: Report time-to-first-token and tokens/second over 20 prompts; cost table matches the provider's pricing page. Source: Ollama API docs
  • Ex 2 · Basic · Embedding search from scratch
    Task: Embed 1,000 sentences, store vectors in numpy, and answer queries with cosine similarity (no vector DB).
    Verify: Top-3 results for 10 hand-written queries are sensible; per-query latency; compare with a brute-force check. Source: Sentence Transformers
  • Ex 3 · Intermediate · RAG with an eval set
    Task: Chunk a docs folder, embed, retrieve top-k, build the prompt and answer with citations.
    Verify: Write 20 questions with known source passages; report hit@1/3/5 for chunk sizes 200, 500, 1000. Source: Retrieval-Augmented Generation (Lewis et al.)
  • Ex 4 · Intermediate · Tool-calling agent loop, no framework
    Task: Build an agent loop with 2 tools (calculator, file search), JSON-schema arguments, a max-steps guard and error recovery.
    Verify: A 15-task suite: success rate, mean steps, and zero runaway loops when a tool fails. Source: ReAct: Reasoning and Acting in Language Models
  • Ex 5 · Advanced · KV cache for a tiny decoder
    Task: Add a key/value cache to a small GPT decoder so each new token only computes attention for itself.
    Verify: Greedy outputs identical with and without the cache; plot tokens/second vs sequence length for both. Source: nanoGPT

Coding exercises — Databases and SQL (5, basic to advanced)

  • Ex 1 · Basic · Ten queries on a small schema
    Task: Model a shop (customers, orders, items) in SQLite and write 10 queries covering joins, GROUP BY/HAVING and window functions.
    Verify: Results equal hand-computed answers on a 10-row dataset; read EXPLAIN QUERY PLAN for each. Source: SQLite window functions
  • Ex 2 · Basic · Index lab
    Task: Load 1M rows and query a non-key column with no index, a single-column index and a composite index (try both column orders).
    Verify: Latency and plan before/after each; show an index being ignored when you wrap the column in a function. Source: Use The Index, Luke
  • Ex 3 · Intermediate · Isolation anomaly lab
    Task: With two concurrent sessions, reproduce lost update, non-repeatable read and write skew.
    Verify: Fill a table of anomaly × isolation level with what you actually observed, then fix each with locking or a stricter level. Source: PostgreSQL: Transaction Isolation
  • Ex 4 · Intermediate · Tiny B-tree
    Task: Implement an in-memory B-tree with insert, search and range scan.
    Verify: Property test against a sorted list for 100k random operations; tree height vs fanout (4, 16, 64). Source: Let's Build a Simple Database
  • Ex 5 · Advanced · Mini LSM store
    Task: Build memtable + write-ahead log + SSTable flush + read path + one compaction.
    Verify: kill -9 during writes, restart: every acknowledged key is still there; report read and write amplification. Source: RocksDB Overview

Coding exercises — Operating Systems (5, basic to advanced)

  • Ex 1 · Basic · Syscalls only
    Task: Write mini cat and wc using only read/write/open syscalls (C or Go syscall).
    Verify: Output matches coreutils; strace -c syscall counts and time for a 1-byte vs 64 KB buffer. Source: read(2)
  • Ex 2 · Basic · Mini shell with pipes
    Task: Implement a shell that runs a | b &gt; file using fork, execve, pipe, dup2 and waitpid.
    Verify: Compare outputs with bash for 10 pipelines; ps shows no zombie processes afterwards. Source: OSTEP: Process API
  • Ex 3 · Intermediate · Page-fault lab
    Task: mmap a 1 GB file and touch it sequentially, then randomly.
    Verify: Predict minor/major fault counts first; compare with /usr/bin/time -v or perf stat; repeat with a warm page cache. Source: mmap(2)
  • Ex 4 · Intermediate · User-space scheduler
    Task: Build round-robin and priority schedulers for cooperative tasks (coroutines or ucontext).
    Verify: With 4 equal tasks each gets within 5% of the CPU slices; compare mean turnaround vs FCFS on mixed job lengths. Source: OSTEP: Scheduling Introduction
  • Ex 5 · Advanced · Mini container
    Task: Use clone/unshare for PID, mount and UTS namespaces and a cgroup v2 memory limit, then run a shell inside.
    Verify: ps inside shows PID 1; allocating past the limit gets the process OOM-killed; hostname change doesn't leak out. Source: namespaces(7)

    Task: Write a lexer for an arithmetic language with variables and report errors as line:column.

  • Ex 2 · Basic · Pratt parser and tree-walk evaluator

    Verify: An allocation-heavy loop keeps memory bounded; a stress mode that collects on every allocation never frees a live object. Source: Crafting Interpreters: Garbage Collection

Coding exercises — Terminals and Shell (thin) (5, basic to advanced)

  • Ex 1 · Basic · Log analysis with pipelines
    Task: Using only grep, awk, sort, uniq, cut and xargs, answer 10 questions about an nginx access log.
    Verify: Every answer matches a Python script over the same file. Source: The GNU Awk User's Guide
  • Ex 2 · Basic · Safe bash script
    Task: Write a script with set -euo pipefail, option parsing and a trap that cleans up temp files.
    Verify: ShellCheck reports 0 warnings; tests (bats or plain asserts) cover a failing step and Ctrl-C cleanup. Source: Google Shell Style Guide
  • Ex 3 · Intermediate · PTY wrapper
    Task: Write a program that spawns a shell in a pseudo-terminal, forwards I/O and handles window-resize signals.
    Verify: vim and top render correctly inside it; stty size changes when you resize the outer window. Source: pty(7)
  • Ex 4 · Intermediate · ANSI TUI
    Task: Build a small TUI (progress bar, colours, cursor movement, alternate screen, arrow-key input in raw mode).
    Verify: Looks right in 3 terminals; no flicker on redraw; the terminal is restored after Ctrl-C or a crash. Source: XTerm Control Sequences (ctlseqs)
  • Ex 5 · Advanced · Mini tmux
    Task: Build detach/attach with a server process owning the PTY and clients connecting over a Unix socket.
    Verify: Kill the client, reattach: the child process is still running with its scrollback; two clients mirror each other. Source: tmux wiki
