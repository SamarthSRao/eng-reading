Go — Basic · unit 8/36

Interfaces and composition (embedding)

Questions you must be able to answer aloud:

  • What is an interface in Go and how is it satisfied implicitly?
  • What is the empty interface / any, and what is a type assertion and type switch?
  • Why is an interface holding a nil pointer not equal to nil?
  • What is struct embedding and how does it differ from inheritance?
