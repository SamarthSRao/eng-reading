Project ideas

  • EnvChain Compilers — implements nested environments and statement execution from Crafting Interpreters, ch. 8 "Statements and State".
  • OriginPool Infrastructure — implements a Pingora-style origin pool (health, timeouts, reuse) from the Pingora article.
  • FlannelMini Backend — implements an app-level edge cache with request coalescing shaped by Slack Flannel.
  • IdxShard Databases — implements local-per-partition secondary indexes vs one global index, as explained in Arpit's partitioned-indexes article.
  • PipePair Terminals — implements | as two children + an anonymous pipe from Beej IPC and OSTEP's files story.
  • ProgImg Frontend design & performance — implements progressive JPEG/WebP delivery and measured LCP from the Cloudflare progressive-images article.
  • EpsQ Reinforcement learning — implements ε-greedy tabular Q-learning (with a SARSA twin) aimed at unit-6 control, using the reward shape you will later feed Fleet.
  • UseCheck Napkin math — implements a tiny USE-method checklist harness for one host from Gregg's USE Method.
  • AwaitAll JavaScript — implements parallel vs sequential async/await and a minimal Promise.all from those javascript.info chapters.
  • TimeoutRace Go — implements the timeout / abandon patterns from Timing out, moving on on a three-stage pipeline.
  • CowList Java — implements / measures CopyOnWriteArrayList behaviour against ArrayList+lock from Arpit's CoW article and the Collections framework.
  • LoxEval Compilers — implements the recursive evaluate visitor and runtime value types from Crafting Interpreters, ch. 7 "Evaluating Expressions".
  • Pow2Pick Infrastructure — implements power-of-two-choices selection from Mitzenmacher et al., "The Power of Two Random Choices" and the interactive Sam Rose, "Load Balancing".
  • AsideCache Backend — implements cache-aside with TTL and single-flight coalescing, as shaped by Nishtala et al., "Scaling Memcache at Facebook".
  • BPlusLeaf Databases — implements B+tree leaf/internal pages, search and split from DDIA ch. 3 "Storage and Retrieval" (and the write-optimized tree view in the paper below).

  • SrcSetLab Frontend design & performance — implements responsive srcset + lazy-load + explicit dimensions, measured under Early Hints-style preload from the Cloudflare article above.
  • QGrid Reinforcement learning — implements tabular Q-learning (and a SARSA twin) from Sutton & Barto ch. 5–6 ideas, aimed at the control algorithms in unit 6.
  • RhoCurve Napkin math — implements an M/M/1 (and M/M/c) latency-vs-utilisation plot from the queueing story in Brooker and MCS ch. 20's concentration intuition.
  • ThenCatch JavaScript — implements a minimal Promise state machine (pending/fulfilled/rejected) and then chaining from You Don't Know JS, Async & Performance, ch. 3 "Promises".

  • CollBench Java — implements head-to-head benchmarks of ArrayList vs LinkedList vs HashMap/TreeMap from the Oracle Collections interfaces and implementations lessons.
