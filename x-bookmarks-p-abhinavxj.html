Daily Go Series#1

Strings
it's not what you think it is!

Let's talk about strings in Go.
In languages like Java, string is a collection of char data type.
but in Go, a string is a UTF8 encoding of Unicode characters.

What's Unicode??

We know that machines only understand numbers, so in earlier English programming languages we needed a way to represent characters as numbers. So the ASCII format was developed which mapped all the letters in English alphabets to a number.

But ASCII had a problem, it only had 7 bits to represent means max 127 chars. There was no way to represent an emoji, or a letter in Chinese, Hindi etc.

To fix this, Unicode was developed. A Unicode maps any character of any language or emoji into an integer.

What's UTF8?
It's just a method to store Unicodes in form of bytes

String in Go isn't a normal string!

It's a descriptor ( or a struct u can say ) which has 2 fields, a pointer to where the actual string is located in the memory and length of the string.

And yea, just like in Java and Python, strings are immutable in Go
